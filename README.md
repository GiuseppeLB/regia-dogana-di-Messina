# La Regia Dogana di Messina – La via dei tesori
Sito statico (Jekyll) per GitHub Pages. Contenuti in `_pagine/` (8 pagine) e `_oggetti/` (28 schede).
1. Crea un repository GitHub (nome consigliato: `regia-dogana`) e carica tutti questi file.
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Modifica in `_config.yml` `url` e `baseurl` con l'indirizzo reale.
4. Modifica i contenuti da app.pagescms.org (accesso con GitHub).
5. A sito online: `python3 qr/genera_qr.py https://NOMEUTENTE.github.io/regia-dogana`.
ATTENZIONE: i nomi dei file determinano gli URL (e quindi i QR). Cambia pure i titoli, non rinominare i file.
Per aggiungere oggetti (es. pagina 8 fino a sei): nuovo oggetto dal CMS, campo "Pagina di appartenenza".
